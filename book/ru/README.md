# Паттерны проектирования баз данных

Каталог паттернов проектирования баз данных в духе «Банды четырёх». Паттерны описывают повторяющиеся задачи проектирования схемы и работы с данными и способы их решения. Речь о реляционных базах данных приложений; эталонный движок — PostgreSQL. В разделе об **антипаттернах** разобраны типовые ошибки.

Паттерны сгруппированы по областям работы. [Оглавление](SUMMARY.md) задаёт порядок глав и служит навигацией книги.

Книгу создал [Кирилл Мокевнин](https://github.com/mokevnin).
